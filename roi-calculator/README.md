# ROI calculator

A single self-contained HTML page (no build step, no tracking). Visitors enter their own numbers (inquiries per month, how many slip through, close rate, customer value, hours spent on admin, hourly cost) and see the yearly cost of slow follow-up and manual work, with the math shown.

Design choices:
- Uses only the visitor's numbers; no industry averages or promised results.
- Shows the cost of the problem, not a price.
- Responsive (container queries), works embedded in a page builder or on its own.

Open `index.html` in a browser to try it.
